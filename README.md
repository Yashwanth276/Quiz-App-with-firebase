# Quiz-App-with-firebase

🧠 Quiz App with Firebase
A web-based interactive quiz application built using HTML, CSS, JavaScript, and Firebase Firestore. Users can take a 10-question general knowledge quiz, get scored in real-time, and save their score to a Firebase-powered leaderboard.

🚀 Features
🎯 10 General Knowledge Questions

🎵 Sound Effects for Correct & Incorrect Answers

⏳ Countdown Timer + Progress Bar for Each Question

📊 Firebase Firestore Leaderboard (Top 5 Scores)

🔁 Retry Option after Quiz Completion

✅ Responsive UI with Smooth Animations

🛠️ Technologies Used
Frontend: HTML5, CSS3, JavaScript

Firebase:

Firestore (database)

Firebase SDK v11.7.3
